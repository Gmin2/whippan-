# whippan gallery

the public showcase for whippan films, a faithful port of the svg-harness
playground layout (rail fisheye, live preview cards, skiper-style dock)
with the whippan engine rendering every frame. separate app from the
studio editor.

dev: `npm install && npm run dev` (port 8901).
engine artifacts in `vendor/` and `public/` are build outputs of the
whippan repo; rebuild there and re-copy.
